AÇAÍ STIVY — PRÉVIA DO SITE
===========================

Arquivos:
- index.html: página completa, estilos e interações básicas.

COMO VISUALIZAR NO COMPUTADOR
1. Extraia o arquivo ZIP para uma pasta.
2. Abra a pasta.
3. Dê dois cliques em index.html. Ele abrirá no navegador.
4. A prévia usa imagens externas e Google Fonts, então a internet precisa estar ligada.

ANTES DE PUBLICAR
- Confirme os preços reais, tamanhos, produtos e adicionais.
- No final do index.html, procure: const WHATSAPP_NUMBER = "";
- Coloque o número oficial da loja com código do país e DDD, somente números. Exemplo de formato: 5565999999999.
- As taxas e prazos de entrega em VG ainda precisam ser definidos.
- O carrinho atual monta o pedido e o encaminha ao WhatsApp quando o número for configurado. Não é um checkout com pagamento online.
- Este projeto ainda não está publicado nem conectado a domínio, banco de dados ou painel administrativo.

ESTRUTURA
- Projeto independente da ST IMPORTS.
- HTML, CSS e JavaScript em um único arquivo para facilitar a primeira prévia.
